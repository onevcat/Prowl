# Source attribution

The mirror wire protocol, Network.framework transport and saved-connection implementation
in `ProwlMirror-iOS/Infrastructure` are adapted from `onevcat/Prowl` and the
`Awhisper/Prowl` remote-mirror work. Their source license and copyright notice are
preserved in [Prowl-LICENSE](Prowl-LICENSE).

The history-page gate helper in `ProwlMirror-iOSTests/HostFixture` is also
adapted from that implementation and covered by the same notice. The tests do
not embed a complete Host server implementation.
