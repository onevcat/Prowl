`selectedWorkspaceID` / `selectedPaneID` 全局唯一

只有单 socket connected / failed
machine header 状态与 stale cache
connecting、online、reconnecting、attention、disabled；stale 不可操作。

Prowl sidebar 直连本地 server
Prowl 绑定当前 Herdr client-local contract
Herdr client 仍是唯一 terminal/surface authority，Prowl 只做 native chrome。
